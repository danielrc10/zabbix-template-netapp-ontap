# Upstream template source

`official_netapp_aff_a700_http.yaml` is an unmodified export of Zabbix's official `NetApp AFF A700 by HTTP` template, vendor version `7.4-1`.

Upstream project: <https://github.com/zabbix/zabbix/tree/release/7.4/templates/san/netapp_aff_a700_http>

It is stored here so generation is reproducible and the validator can prove that generated UUIDs do not collide with the official template. See the repository [NOTICE](../../../NOTICE.md) and [AGPLv3 license](../../../LICENSE).
