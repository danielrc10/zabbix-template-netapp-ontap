# Segurança / Security

## Português

Não publique vulnerabilidades, credenciais, respostas brutas da API, endereços internos, números de série ou informações de clientes em issues públicas. Envie relatos de segurança diretamente para [danielrc10@gmail.com](mailto:danielrc10@gmail.com), incluindo versão afetada, impacto e uma forma segura de reprodução.

Nunca grave valores de `{$NETAPP.URL}`, `{$NETAPP.USERNAME}` ou `{$NETAPP.PASSWORD}` no arquivo YAML. Configure-os como macros do host e mantenha a senha como texto secreto.

## English

Do not publish vulnerabilities, credentials, raw API responses, internal addresses, serial numbers, or customer information in public issues. Send security reports directly to [danielrc10@gmail.com](mailto:danielrc10@gmail.com), including the affected version, impact, and a safe reproduction method.

Never store `{$NETAPP.URL}`, `{$NETAPP.USERNAME}`, or `{$NETAPP.PASSWORD}` values in the YAML file. Configure them as host macros and keep the password as secret text.
