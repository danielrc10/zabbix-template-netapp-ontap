# Contribuindo / Contributing

## Português

Contribuições são bem-vindas. Abra uma issue descrevendo o problema ou envie um pull request pequeno e objetivo.

- Preserve a compatibilidade declarada com Zabbix e ONTAP.
- Mantenha cada implementação em `zabbix-<versão>/`.
- Altere o gerador, gere novamente o YAML e execute o validador.
- Não inclua credenciais, endereços internos, UUIDs reais, números de série, respostas brutas da API ou dados de clientes.
- Use somente dados fictícios nos testes.
- Explique como a alteração foi validada.

Ao enviar uma contribuição, você concorda que ela seja distribuída sob a [GNU Affero General Public License v3.0](LICENSE).

## English

Contributions are welcome. Open an issue describing the problem or submit a small, focused pull request.

- Preserve the declared Zabbix and ONTAP compatibility.
- Keep each implementation under `zabbix-<version>/`.
- Change the generator, regenerate the YAML, and run the validator.
- Do not include credentials, internal addresses, real UUIDs, serial numbers, raw API responses, or customer data.
- Use fictional data in tests only.
- Explain how the change was validated.

By contributing, you agree that your work is distributed under the [GNU Affero General Public License v3.0](LICENSE).
